# 正文内嵌图片

用户确认：当前只看到文字入口，希望正文内直接显示图片。本设计替代弹窗阅读设计中的图片点击加载决定。实现任务由 fork 的 GitHub Issue #19 跟踪。

- 描述和已读取评论共用安全正文渲染器，图片直接显示，保持文字前后顺序及原有格式。
- 图片保持原始宽高比，受当前正文/单元格宽度约束，不放大小图；窄屏不溢出。
- 显示加载提示，失败后显示可理解的提示及重试；保留图片说明与「查看原图」，支持键盘操作和可见焦点。
- 继续复用安全解析器：相对地址按单据 URL 解析，只接受 HTTP(S)，拒绝脚本等危险协议及携带账号密码的 URL。地址无效时只显示说明。
- 图片由客户端直接请求正文中的图片 URL，不添加配置的 TAPD 凭据、不新增 daemon 代理。浏览器可能使用站点 Cookie；受保护图片的登录限制仍由原站决定。
- 不修改连接信息、筛选、收藏、视图或 Agent 关联，不执行真实 TAPD 写入。

验证：先用真实工作台组件复现「存在图片说明但图片元素为 0」，再验证加载成功、失败重试、尺寸/顺序、原图键盘操作与窄屏；使用仓库已有图片作为本地只读测试资源，不生成或改动截图及图片。保留完整正文、弹窗切页及草稿保护的现有回归。
