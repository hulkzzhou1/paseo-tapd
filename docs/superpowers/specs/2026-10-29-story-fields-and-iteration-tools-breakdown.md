# 规格 #81 的已发布任务图

状态：已按本轮 to-tickets 指令发布 5 个子任务（#82—#86），均标记 ready-for-agent。父子关联及 4 条原生阻塞关系已回读核实，尚未开始实施。

## 1. #82 需求详情的短自定义属性只读展示

依赖：无，可开始。

交付：通过实际项目及需求类别定义读取短字段，在侧栏和工作台详情展示前 6 个非空值、更多数量及显示空字段。覆盖文本、数值、枚举/多选、人员、日期，保留零、false、空、未知、缺失及失败的区别。元数据失败不阻塞基础详情；初始读取不预取自定义富文本值。现有 Agent 字段写入约束不变。

验证：注册工具/真实 RPC 对接隔离 HTTP，及实际详情组件调用真实 RPC。验证跨项目/类别隔离、未知类型、部分失败、短属性展开及原有详情操作。

## 2. #83 富文本页签、按需加载与阅读交互

依赖：#82。

交付：在相同详情中提供按定义顺序排列的自定义富文本页签，固定概要；切页才读取，支持空入口、局部失败、重试、手动刷新与安全正文/图片。评论和关联单据留在详细信息，各页保留写评论操作；本次打开保留各页阅读位置，关闭重开及换单重置。兼容侧栏/弹窗、窄屏、主题和键盘。

验证：注册 RPC 和实际 UI→隔离 daemon/RPC 两个公开边界，检查 HTTP 请求以证明未预取；覆盖竞态、阅读位置和既有操作草稿保护。

## 3. #84 当前迭代及实际项目候选读取工具

依赖：无，可开始。

交付：Agent 可读取需求、任务、缺陷的原始迭代编号与返回状态，并取得实际项目内的候选、项目归属、日期/状态及分页完整性信息。区分未返回、未知、未设置与具体编号；不从名称猜编号，不把跨项目聚合筛选候选当写入依据。本任务仅读。

验证：实际注册工具与真实 RPC 对接隔离 HTTP，覆盖三种单据、目标/项目/类型不匹配、跨页、重复名称、截断、部分失败和旧在途请求。

## 4. #85 单张需求、任务和缺陷的受控迭代更新

依赖：#84。

交付：Agent 获明确授权后，为一张单据设置或更换同项目已有迭代，核对原值及候选，不变则不写；冲突停止，单次 POST 后新鲜回读。拒绝、未知及已接受未核实保留真实语义，不自动重复；复用结果反馈及详情/看板刷新，展示失败不重放。只写迭代字段，不联动子单、状态、人员或责任关系，不解除或创建迭代。

验证：注册工具/真实 RPC 的隔离 HTTP 验收覆盖三类目标、授权、归属、旧值、清空拒绝、无变化、失败/未知/回读及展示故障。缺陷部署兼容性需单独记录真实证据，不能把合成通过冒充已验证生产写入。

## 5. #86 联合验收、文档/技能同步与本机交付

依赖：#83、#85。

交付：对规格整体完成混合读取与工具更新、刷新和既有业务回归；同步用户文档、manifest、版本及 TAPD skill，完成规范和规格双轴审查，沿用 fork 集成 PR 流程交付，并仅重载本机插件核对配置、关联及会话保留。

验证：两项功能各自的公开边界加混合场景；Node、类型、lint 与对应 UI/RPC 检查。实际部署只读核对字段及候选，真实写入未知如实报告；不改真实业务单、不截图、不重启 daemon。
