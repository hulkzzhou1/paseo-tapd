## 01 — 单张查询结果卡片直达完整详情

**Issue:** [#28](https://github.com/hulkzzhou1/paseo-tapd/issues/28)

**Blocked by:** None — can start immediately.

**What it delivers:** Agent 查询一张 TAPD 单据后，对话显示可点击的结果卡片；点击直接打开与工作台一致的完整详情和操作页，关闭后回到原对话。

- [x] 真实单张查询工具的结果生成 schema 校验的单据卡片，不额外查询未知元数据。
- [x] 卡片携带准确项目、类型和单号以及已有摘要，显示失败或部分失败信息，不伪造成功。
- [x] 从卡片打开共享详情，完整保留正文、图片、关联单据、评论、状态、子建单、派发和绑定能力，以及确认、草稿保护和返回行为。
- [x] 工作台原有功能继续可用，当前工作台筛选不限制卡片打开的单据。
- [x] 工具入口及真实组件交互测试覆盖成功、失败、打开/返回、窄屏与键盘操作；不执行真实 TAPD 写入。

## 02 — 会话单据入口与完整生命周期恢复

**Issue:** [#29](https://github.com/hulkzzhou1/paseo-tapd/issues/29)

**Blocked by:** [#28](https://github.com/hulkzzhou1/paseo-tapd/issues/28)

**What it delivers:** 单张查询的单据进入输入框上方的会话入口；可以整理、移除，并在重开会话和重启后恢复引用及卡片摘要，随所属会话归档或删除。

- [x] 无会话单据时隐藏入口，一张时点击直达详情，多张时展开可操作列表。
- [x] 按主机、Agent、项目、类型、单号正确隔离；同一单据去重，最近涉及或打开的优先。
- [x] 支持移除，保留历史卡片和 TAPD 单据；历史重放不会恢复已移除条目，新单张查询或主动打开可以重新收录。
- [x] 使用独立、经过校验和原子更新的本机持久记录，保存最小引用、卡片摘要及移除/重放进度；不保存正文、评论全文或凭据，不进入 Git 配置同步。
- [x] 客户端未打开时单张工具结果也可收录，重开、插件重载和新 daemon 进程中能恢复；恢复只重建展示，不重复执行工具。
- [x] 归档保留，恢复可用，删除所属会话后清理；断连、分页不可见和归档不被误判为删除；不另设到期时间。
- [x] 用公开边界和跨进程测试验证恢复、去重、移除、隔离和中断保存，不改用户现有配置；最终真实 daemon 场景在任务 06 汇总验收。

## 03 — 建单、评论和状态操作结果就近触达

**Issue:** [#30](https://github.com/hulkzzhou1/paseo-tapd/issues/30)

**Blocked by:** [#29](https://github.com/hulkzzhou1/paseo-tapd/issues/29)

**What it delivers:** Agent 成功创建单据、发表评论或修改状态后，结果卡片准确呈现操作结果，同时将目标加入会话入口，可立即打开详情。

- [x] 三类写工具仅在已知成功后生成成功结果卡片，并保存所属会话的最小结果摘要。
- [x] 使用实际项目及已有操作信息，不把卡片快照误标为实时详情；未知字段保持未知。
- [x] 持久化、时间线追加或显示失败不改变已成功的 TAPD 写入结果，不触发自动写入重试；提供安全、可恢复的展示警告。
- [x] 失败、取消及不确定写入不伪造成功；保持现有确认、项目核对、凭据隔离及重复提交保护。
- [x] 被移除的目标因新的成功操作重新收录，单张打开及会话恢复行为与任务 02 一致。
- [x] 模拟工具测试覆盖三类写入、成功后的展示故障、取消和恢复；浏览器交互验证卡片直达共享详情，不执行真实 TAPD 写入。

## 04 — 普通消息中的明确链接自动收录

**Issue:** [#31](https://github.com/hulkzzhou1/paseo-tapd/issues/31)

**Blocked by:** [#29](https://github.com/hulkzzhou1/paseo-tapd/issues/29)

**What it delivers:** 用户或 Agent 在普通消息中发出明确 TAPD 链接后，当前对话入口出现相应编号；点击读取详情，原消息和普通链接行为保持不变。

- [x] 只识别配置站点及项目的合法单据 URL，不把数字、模糊标题或其他站点链接猜作单据。
- [x] 扫描和收录不自动读取 TAPD 摘要或正文；未知单据先显示编号，已有工具摘要可以复用。
- [x] 历史补取、流式更新、重连和消息重放不重复收录、不恢复已移除旧条目；新的明确提及可以重新收录。
- [x] 原始消息和原有链接点击保持不变，不在时间线转换器中执行写入或网络操作。
- [x] 不扫描原始批量工具结果为普通消息链接，维持批量点击后收录的边界。
- [x] 消息输入公开边界和界面测试验证收录、无额外请求、隔离、重放及点击加载，不只靠扫描固定条数的历史尾部恢复。

## 05 — 批量结果卡片与选中后收录

**Issue:** [#32](https://github.com/hulkzzhou1/paseo-tapd/issues/32)

**Blocked by:** [#29](https://github.com/hulkzzhou1/paseo-tapd/issues/29)

**What it delivers:** 搜索或看板查询返回多张单据时，对话显示默认五条的紧凑结果列表；展开查看更多已返回结果，点击打开详情并加入会话入口。

- [x] 搜索和看板批量结果产生可恢复的结果记录，默认展示前 5 条；展开或分页能访问其余已返回结果。
- [x] 不把整个批次自动加入聚焦会话入口，点击某张后才收录并更新最近顺序。
- [x] 保留总数、部分失败、缓存状态和截断信息；空结果及失败清楚区分，不把截断结果声称为全量。
- [x] 大结果使用有界摘要、引用及分页展示，遵守宿主时间线负载上限，不静默丢掉已返回条目。
- [x] 与真实工具入口及公开组件交互测试一起验证五条展开、选择、重复条目、错误/截断、较大结果及恢复。

## 06 — 完整会话验收与本机交付

**Issue:** [#33](https://github.com/hulkzzhou1/paseo-tapd/issues/33)

**Blocked by:** [#30](https://github.com/hulkzzhou1/paseo-tapd/issues/30), [#31](https://github.com/hulkzzhou1/paseo-tapd/issues/31), [#32](https://github.com/hulkzzhou1/paseo-tapd/issues/32)

**What it delivers:** 一段混合单张查询、普通链接、批量查询和单据操作的真实会话，在关闭、重载、重启及归档恢复后仍可快速访问正确单据；验证完成后交付本机可用版本。

- [x] 在独立测试 daemon 中，用 mock TAPD 完成客户端离线、插件重载、真实 daemon 重启、归档/恢复和会话删除的完整验收。
- [x] 验证卡片和入口恢复、旧历史不复活移除项、新触达可收录、跨主机/会话隔离，及全程零重放写入。
- [x] 检查实际宿主的输入框按钮登记、无工作区场景兼容性、直接结果卡片入口，以及共享详情在键盘、主题和窄屏下的完整流程。
- [x] 全部切片已有各自测试；本任务只补交叉场景和真实运行时证据，不将前面任务的测试推迟到此处。
- [ ] 同步用户文档、数据流说明、清单和版本；安全扫描、主线 SDK 类型检查、lint、Node 及浏览器回归、规范/需求审查通过。
- [ ] 保留原连接和全部用户配置，按既有流程合入 fork 主线并重载本机插件；真实环境只读验证，不卸载重装、不改真实 TAPD 单据、不生成媒体。

## 已提供的交叉验收

- `npm run test:daemon`：独立真实 daemon 进程、模拟 TAPD、离线收录、读写及链接混合场景、批量选择与分页、重载与真实进程重启、移除旧重放和新提及、归档/恢复、真实删除及零重放写入。
- `npm run test:ui`：完整共享详情/操作回归，加会话按钮登记卸载/重建、无工作区卡片入口、键盘返回和窄屏深色展示；不生成媒体。
- 会话按钮从插件根贡献登记，独立于侧栏；无工作区会话使用直接结果卡片。主线公开 Icon 组件承载详情及操作，保持宿主交互与草稿确认。
