# Agent 工具关联的存储

服务端主线 SDK 提供 Agent/工作区创建，但插件设置仅支持读取和订阅，不能通过公开 API 保存旧客户端设置中的关联。

工具产生的关联因此写入插件自己的 `plugin-data/tapd-workbench/agent-links.json`，以 API 地址、TAPD 项目、单据类型/编号和 Agent 为键，串行原子更新。客户端合并旧设置关联与当前连接下的工具关联，同一单据/Agent 优先显示工具记录；解除时分别移除工具记录和旧设置对应项。旧配置不迁移，不调用内部设置协议。

代价是新关联不进入原 Git 配置同步，需备份插件数据目录；旧设置无法凭空恢复新工具关联。派发先创建资源、保存关联，再发送提示词；部分失败保留资源并返回阶段和已有 ID，不自动重试或回滚工作区。自动回评继续由用户开关控制，并读取实际 TAPD 项目。
