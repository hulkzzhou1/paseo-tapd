# 需求详情自定义字段展示与单据迭代工具

状态：产品选择已逐项确认，实施规格已发布到 fork GitHub Issue #81，标记 ready-for-agent；尚未进入实施。完整规格见 [需求字段与迭代工具规格](2026-10-29-story-fields-and-iteration-tools-spec.md)。

## 已确认

- 首版在需求详情展示全部可读自定义字段，覆盖技术需求、产品需求等需求类型；不局限于预设业务字段名。
- 字段名称和类型来自实际项目配置。短字段放属性区并可展开更多，富文本使用独立内容页，避免同时铺开大量字段。
- 本轮页面仅提供字段阅读，不新增字段编辑入口；编辑继续使用现有 Agent 字段工具及其授权、旧值校验和回读规则。
- 顶部保留标题、状态、操作和关联 Agent，默认进入“详细信息”。自定义富文本各有独立页签，名称使用实际字段定义；窄侧栏允许横向滚动页签。
- 短字段默认隐藏已确认空值，提供“显示空字段”入口；富文本页签即使为空也保留入口，确认空内容时显示“尚未填写”。未返回、无法识别和读取失败分别提示，不冒充空值。
- 富文本在切换到对应页签时加载，失败仅在该页提供重试，不阻塞其他页面，并提供手动刷新。
- 评论和关联单据集中在“详细信息”；富文本页只展示对应字段内容，顶部“写评论”操作在所有页签可用。
- 同一次打开期间保留各页阅读位置；关闭后重新打开默认“详细信息”，切换另一单据时重置。
- 自定义属性默认显示前 6 个非空短字段，其余通过“更多属性（N）”展开；展开后仍可选择显示空字段。富文本页签按字段定义返回顺序排列，本轮不增加排序设置。
- 展示适用于共用的需求侧栏详情和工作台弹窗，沿用现有正文、图片及链接的安全呈现。
- 用户提供的 TAPD 页面截图仅作设计参考，不写入仓库。

## 已核对的现状

- 共用需求详情当前仅返回、渲染固定属性、需求描述、标签、关联单据及评论，没有传递通用自定义字段集合。
- Agent 字段工具已支持发现、读取及受控更新需求文本和富文本字段；枚举、人员、日期等字段的通用只读展示需要补充读取及呈现能力。
- 沿用现有详情、正文和内嵌图片的展示与安全规则。现有阅读及操作约束参见 [详情阅读与弹窗统一](2026-10-27-dialog-reading-design.md) 及其后续调整。

## 追加需求：设置迭代

用户要求补充 Agent 工具的设置、更新单据迭代能力。此为独立业务字段写入，不是本轮详情字段编辑入口。

已确认覆盖需求、任务和缺陷，每次只更新明确指定的一张单据，候选必须来自该单据的实际项目。

首版只设置或更换为同项目的已有迭代，不包含解除迭代。

现有工具仅在新建单据时接受迭代；受控文本字段更新不覆盖迭代字段，不能替代现有单据的迭代更新工具。

现有跨项目迭代筛选候选每项目只取一页，且不携带可验证的项目归属，不能直接作为写入依据。新增工具需要读取实际迭代编号，区分未返回、未设置和具体迭代，不能从显示名称反推。沿用项目和目标核对、明确授权、旧值冲突检查、无变化跳过、单次提交与新鲜回读；不自动修改子单、其他字段或重复未知写入。

官方 [查询迭代](https://open.tapd.cn/document/api-doc/API文档/api_reference/iteration/get_iterations.html) 支持分页并返回项目归属；[更新需求](https://open.tapd.cn/document/api-doc/API文档/api_reference/story/update_story.html) 和 [更新任务](https://open.tapd.cn/document/api-doc/API文档/api_reference/task/update_task.html) 明确列出迭代参数。[更新缺陷](https://open.tapd.cn/document/api-doc/API文档/api_reference/bug/update_bug.html) 文档列参不完整，不能由此断言不支持，仍需实现与部署兼容核对。尚未找到解除迭代的明确请求语义，不通过猜测空串或零值填补。

## 验证方向

沿用已确认的两个公开边界：注册工具和真实 RPC 对接隔离 HTTP，验证字段定义/原值状态、迭代项目归属、完整性、冲突、拒绝、未知及回读结果；实际详情组件调用真实 RPC，验证短属性、富文本页签、按需加载、空/未知/失败、阅读位置，以及侧栏、弹窗和窄屏行为。保持现有字段编辑与单据操作回归，测试不改真实 TAPD 数据、不生成截图。

后续规格沿用这些已确认的产品选择；缺陷接口的部署兼容核对属于验收事实，不通过猜测或真实业务单据试写代替。
