# 详情阅读与弹窗统一

状态：用户已确认五项产品决定，2026-10-27。此前筛选与空列改动分别由独立 PR 交付。

## 确定的交互

- 沿用现有主题和已优化设置弹窗的风格；统一标题、留白、边框、圆角、关闭入口、输入和操作按钮。不同用途保留适合的尺寸。
- 桌面详情宽度约 1000px，受窗口边距约束；正文限制阅读行宽，标题、状态和关键属性在前，描述为阅读主区，关联信息和评论随后。窄屏单列。
- 保留完整描述和评论内容，安全展示原文的标题、段落、列表、引用、链接、代码和表格结构；不再静默截成 4000 / 800 字。评论数量仍沿用已有最近 30 条读取。
- 图片保留说明和「查看原图」入口，点击才打开，不自动下载远程图片。外部链接仅在点击时打开，拒绝非 HTTP(S) 等危险协议；不把 TAPD 凭据传给链接目的地。
- 从详情进入新建、派发、绑定、评论等操作时，使用同一弹窗内的操作页与「返回详情」，保留原单据和阅读位置，避免叠加弹窗。状态修改继续使用已确认的即时下拉交互。
- 新建表单字段按用途分区，全部可见，保留用户已有字段顺序、隐藏设置及必填语义；桌面合理分列、窄屏单列。保持当前编辑数据与提交语义。
- 新建或评论有未提交改动时，关闭或返回先确认是否放弃；空表单直接返回。确认在当前弹窗内展示，避免新的弹窗层。
- 所有弹窗支持键盘、可见焦点、仅当前页面关闭、窗内滚动、浅色与深色主题。下拉菜单保持菜单语义。

## 实现约束

当前 SDK 0.11.2 没有公开 Markdown 或可调宽度的 SDK Modal。基于公共 React Native Modal 与已有主题统一外壳，不引入私有宿主 API 或新依赖。正文仅渲染受支持的结构和安全文本，不执行远程 HTML / 脚本 / 样式。保留单独纯文本快照供 Agent 提示词使用，避免将展示结构塞入提示词。

不新增 TAPD 查询目的地、图片自动请求、配置迁移或卸载流程。更新 README、OVERVIEW、清单及版本。截图、真实 TAPD 写入、原生硬件验证不作为自动化检查步骤。

## 验证边界

- 模拟 TAPD 的详情接口：完整内容、安全结构、原有纯文本快照及评论兼容。
- 实际弹窗/详情/表单组件：桌面和窄屏宽度、滚动、键盘/关闭与焦点恢复、详情内操作返回、未保存确认、原有创建/回写流程与失败反馈。
- 既有 Node 测试、类型检查、lint 与浏览器交互检查；完成规范与规格两路审查后合入 fork 主线。本地仅重载现有插件并核对配置指纹。
