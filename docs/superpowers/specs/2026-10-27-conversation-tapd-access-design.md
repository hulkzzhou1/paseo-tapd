# 对话中的 TAPD 快捷触达

状态：Q1–Q9 及生命周期规则已由用户确认；设计收敛，尚未进入实施。

实施规格已整理并发布：[本地规格](./2026-10-27-conversation-tapd-access-spec.md) · [GitHub Issue #27](https://github.com/hulkzzhou1/paseo-tapd/issues/27)。测试边界已获用户确认。

## 目标

在 Agent 对话涉及 TAPD 时，就近打开对应单据；关闭详情后继续原对话，长对话中也不必反复向上寻找旧结果。

## 已确认的行为

1. 会话单据聚焦具体讨论对象：单张查询、建单/操作目标和明确 TAPD 链接自动收录。批量查询结果留在结果列表，点击某张后才加入会话入口。
2. 会话单据和结果卡片跟随所属 Agent 对话的生命周期。关闭窗口、重开或重启 Paseo 后恢复；归档时保留，恢复后可用；删除会话时一并清理。不另设过期时间，不转为全局收藏，按主机和 Agent 隔离。
3. 完整复用工作台现有详情及操作：正文、图片、关联单据、评论、改状态、新建子单据、派发/绑定 Agent。沿用现有确认规则，关闭后回到原对话，操作页继续沿用返回及未提交内容保护。
4. 输入框上方提供 TAPD 入口及单据数量。无会话单据时隐藏；只有一张时点击直接打开详情；多张时展开紧凑列表，再选择单据。
5. 同一单据去重，最近明确涉及或打开的排在前面，可从当前入口移除。移除不删除 TAPD 单据，也不删除历史结果卡片。
6. 创建、评论、状态变更和单张查询显示紧凑结果卡片。批量查询默认显示前 5 条，可展开其余已返回结果，保留部分失败及截断提示；不会把已截断结果描述为全量结果。
7. 用户和 Agent 普通消息中的明确 TAPD 单据链接均自动收录，只识别已配置站点及项目。工具批量结果不经链接扫描自动加入。普通数字和模糊标题不猜作单据，只有标题时先由 Agent 查询确认身份。
8. 新发现但尚未读取的链接先显示单据编号，点击才读取详情；不因扫描链接自动读取 TAPD 正文或摘要。已有工具结果中的标题、状态等摘要可以复用，不猜测未知字段。
9. 移除后，历史扫描、重连和重开会话不会让旧记录重新加入。后续新的明确提及、单张查询/操作或主动点击可以重新收录；需要区分旧历史重放和新触达。

## 展示及数据边界

- 卡片是调用时的结果摘要，详情读取当前数据。打开关联单据、在详情内操作及返回的体验与工作台一致。
- 会话单据仅为对话中的快捷引用，不自动创建派发或绑定 Agent 的业务关联。
- 标识同时考虑主机、项目、类型、单号；来自其他主机、未配置站点或项目的链接不擅自读取。
- 保留普通用户和 Agent 消息的原文及原有链接行为，不替换整段回复来拦截普通链接。自有结果卡片及会话入口负责直接打开详情。
- 写入成功与结果展示分开：卡片登记、刷新或持久化失败，不得把已成功的 TAPD 写入报告为失败或自动重试。恢复卡片仅恢复摘要展示，不重放任何写入。
- 持久记录只包含恢复入口和结果卡片所需的引用、短摘要及移除/历史进度信息，不保存正文、评论全文或凭据，不进入现有 Git 配置同步。
- 读取失败时保留可识别的引用并提供重试；不伪造标题和状态，不把失败当作单据不存在。

## 已核对的 SDK 事实

本机主线 commit：`6b7d49f0d8d21d01565f9517a8c2a30e2a587e2a`。

- 支持 Agent 工具、插件时间线追加/渲染及 Agent 输入框按钮；已有工作台详情和操作页可复用。
- 公共时间线订阅可观察用户及 Agent 消息而保留原文。恢复需要补取历史并处理重连，不能只扫描末尾少量消息。时间线 transformer 必须同步、确定、无副作用。
- 没有公开的普通消息链接全局点击拦截接口；自有组件可以打开详情弹窗。
- 插件时间线行不能单独承担重启恢复：虽然 AgentManager 存在可选 durableTimelineStore 路径，当前生产 bootstrap 没有装配。需保证引用与卡片记录实际持久化，并在重建时恢复运行时登记。
- 服务端 registerSettings 只有 read/subscribe，没有公开 save。适合当前 SDK 的方案是独立的插件本地存储，支持客户端未打开时工具结果的收录；不直接修改 Paseo 内部设置文件，写入需原子化，沿用项目隔离和安全错误处理。
- 输入框按钮要求 Agent 有工作区。无工作区 Agent 的宿主兼容性需要在实施中核对；结果卡片是独立入口。

## 实施验证重点

- 真实工具入口及时间线消息输入：单张/批量收录区别、链接识别无额外读取、去重与排序、移除后旧历史不复活、新触达可重新加入、主机与项目隔离。
- 会话生命周期恢复：客户端未打开时工具结果也能收录，关闭/重开、插件重载、真实 daemon 重启后恢复；归档保留，删除会话清理。恢复不重复执行工具写入，不重复生成卡片。
- 用户界面边界：零张隐藏、单张直达、多张列表、批量 5 条展开、失败/截断提示、现有详情与操作页、关闭回到对话、键盘/窄屏/主题；写入成功后的展示失败不导致重复提交。

尚未进行实现、真实重启验证、TAPD 写入或媒体操作。后续实施规格和任务以本文件中已确认的产品行为为依据。
